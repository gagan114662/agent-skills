# SERP Intent Map

Ranking is a matching problem before it's a content problem. Google already decided what *kind* of page wins each query — your job is to read that decision off the SERP and serve it better, not to argue with it.

## The five intents → page type → depth

| Intent | Query signal | Page type that wins | Depth |
|---|---|---|---|
| **Know** (informational) | "what is", "how does", "X vs Y meaning" | Article / guide / glossary | Comprehensive: cover the topic + adjacent questions |
| **Do** (instructional) | "how to", "build", "fix", "template" | Step-by-step tutorial, tool, calculator | Just enough to complete the task; show, don't lecture |
| **Buy** (transactional) | "buy", "pricing", "[product] discount", "best [product] for X" | Product / pricing / category page | Specs, price, proof, CTA above the fold |
| **Compare** (commercial investigation) | "best", "top", "alternatives", "X vs Y", "review" | Listicle / comparison table / review | Multiple options, honest criteria, a table, a verdict |
| **Navigational** | brand or product name | The brand's own destination | The page they're already trying to reach |

A mismatch is fatal: a 3,000-word essay aimed at "buy running shoes" loses to a category page every time, and a thin product page can't win "how to choose running shoes."

## Read the actual SERP (the only real intent source)

Keyword tools guess intent; the live SERP *is* intent. For each target query, open the SERP and record:

1. **Page type of the top 5–10** — all listicles? then a single product page can't rank. All how-to? then write a tutorial.
2. **SERP features** — Featured snippet (answer the question in 40–55 words, early, in the format it shows: paragraph/list/table). PAA boxes (the adjacent questions to cover). Shopping/Local pack (signals buy/local — content alone won't win). Video carousel (Google wants video here).
3. **Content depth & format** — word count band, presence of tables, original data, tools. Match the *median* winner, then beat it on substance.
4. **Mixed intent** — if the top 10 splits across page types, intent is ambiguous; the safest play is a hybrid page or to target a more specific long-tail variant.

## One page per query cluster (topical authority)

Do **not** make one page per keyword. Group queries that share the same intent and answer (e.g. "INP good score", "what is a good INP", "INP threshold" → one page) into a **cluster**, and build **one** definitive page per cluster. Multiple pages for the same intent cannibalize each other — Google picks one and you split your own signals.

Then build **topic clusters**: one pillar page (broad term) linking down to spoke pages (specific sub-queries), spokes linking back. This is how you earn topical authority — covering a subject exhaustively beats covering it shallowly across orphaned pages.

## Prioritize by intent × winnability

Score each candidate query:

- **Winnability** — Keyword Difficulty vs your domain authority; how entrenched are the top results; can you genuinely make a better page than rank #5? Realistically you displace #6–10, not #1, on a new page.
- **Value** — buy/compare intent converts; know intent builds authority and feeds the funnel. Weight by business proximity.
- **Volume × realistic CTR** — a #6 position on a 1,000/mo "compare" query (~3% CTR) often beats #1 on a 10,000/mo "know" query that never converts.

**Prioritize: high-intent + winnable first.** Start with bottom-of-funnel "best/alternatives/[competitor] vs" and long-tail "do" queries you can actually rank for, then expand up the funnel into broader "know" pillars as authority compounds. Build the spokes you can win; let them earn the right to the pillar.

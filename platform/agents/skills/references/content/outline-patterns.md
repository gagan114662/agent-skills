# Outline Patterns

The outline is the argument. Pick the skeleton from the reader's *intent*, not the topic. Every pattern below maps to a query type, a section sequence, and one CTA placement. Build the outline before the first sentence — if the outline only works because of clever prose, the structure is wrong.

## Universal rules (apply to every pattern)

- **Problem-first opening.** First 50 words name the reader's pain in their words. No "in this post we'll cover." Earn the scroll with stakes, not a table of contents.
- **Subheads that tell the story alone.** A reader scanning only the H2s must get the full argument. "Step 3: Map fields" is dead. "Map their column names to yours, or every row silently fails" is alive.
- **One idea per section.** If a section needs "additionally" or "also," split it. Each H2 is one claim plus its proof.
- **CTA earns its place.** One primary CTA, positioned where conviction peaks for that intent (noted per pattern). Never open with the ask.

## The How-To (intent: "how to X" — doer wants a result now)

Query: `how to set up DMARC` · Intent: transactional/instructional.

1. **The outcome + the catch** — what they'll have in N minutes, and the one gotcha that breaks most attempts.
2. **Prerequisites** — exact tools/access, so they don't start and stall.
3. **Steps 1..N** — each H2 is an action verb + the *why* and the failure mode. Numbered, screenshot or command per step.
4. **Verify it worked** — the test that proves success (the section everyone skips and shouldn't).
5. **Common errors** — symptom → cause → fix table.

CTA: after "Verify it worked," when they've succeeded and trust you — "automate this with X."

## The Listicle Done Right (intent: "best X / X tools / X ideas")

Query: `best cold email subject lines` · Intent: commercial survey.

1. **Selection criteria** — how you chose, what disqualifies an item. This is what separates an A listicle from slop.
2. **Items 1..N** — each: name → one-line what-it-is → who it's *for* → the honest trade-off → a concrete example/number. Parallel structure across all items.
3. **How to choose** — a decision shortcut (if you're B, pick item 3).

CTA: inside the item that maps to your product, framed as "for teams that need Y." Subtle, in-context.

## The Comparison / Vs (intent: "X vs Y / X alternative")

Query: `Notion vs Obsidian` · Intent: high commercial — a decision is imminent.

1. **The real question** — what they're actually deciding (not features, the job).
2. **At-a-glance table** — 5-7 dimensions that matter, not 30.
3. **Where X wins** / **Where Y wins** — honest, specific, with the use case each suits.
4. **Pick X if… / Pick Y if…** — bucketed recommendations by reader type.

CTA: inside the "pick X if" bucket that fits your product. Bias loses trust; route honestly and win the right reader.

## The "What Is X" Explainer (intent: informational, top-of-funnel)

Query: `what is RAG` · Intent: definition + understanding.

1. **One-sentence definition** — answerable-snippet ready, plain language.
2. **The problem it solves** — why it exists; the before-world.
3. **How it works** — mechanism, one concrete walked example.
4. **When to use / not use** — boundaries earn authority.
5. **Related terms** — internal-link nest for topical depth.

CTA: soft — newsletter or a deeper guide. They're learning, not buying.

## The Contrarian POV (intent: brand/demand-gen, not search)

Distribution: social/newsletter, not SEO. Intent: provoke a rethink.

1. **The consensus belief** — state what everyone assumes, fairly.
2. **Why it's wrong / costly** — the evidence, the hidden bill.
3. **What's true instead** — your thesis, sharp and falsifiable.
4. **What to do about it** — make the new belief actionable.

CTA: at the emotional peak after "what to do" — they're converted to a worldview; offer the tool that lives in it.

## The Case Study (intent: solution/product-aware, proof-hungry)

1. **Result up top** — the number, before any backstory.
2. **The situation** — who, the stakes, what was failing.
3. **What they tried first** — the dead ends (credibility).
4. **The intervention** — what changed, specifically.
5. **The outcome** — metrics with timeframe and method.

CTA: strong and direct after the outcome — "get the same result." This reader is closest to buying.
